## Part 4 — Separate Final-4 and WWCD Overlay Routing & Visibility Fix (Active)

- **Phase:** Implementation & Verification
- **Objectives:**
  1. Route Isolation: `/main` (`/overlay/:instanceId`) renders strictly the vertical leaderboard; `/final4` (`/overlay/final4`, `/overlay/:instanceId/final4`) renders strictly the horizontal Final-4 top bar; `/wwcd` (`/overlay/wwcd`, `/overlay/:instanceId/wwcd`) renders strictly the WWCD victory screen; `/match-info` renders strictly the match/map pill; `/postgame` renders strictly the post-game standings.
  2. Global Visibility Coordination: Shared state machine coordinates which overlay is visible across States A, B, C, D with WWCD having highest precedence and hiding `/main`, `/final4`, and `/match-info`.
  3. Final-4 Centering Fix: Correct the horizontal centering of `FinalFourOverlay` on the 1920×1080 canvas by eliminating Motion transform collision (`translateY` overriding inline `translateX(-50%)`) through an isolated full-canvas flex centering container (`left: 0; right: 0; display: flex; justify-content: center`).
  4. OBS URLs & Admin Integration: Add copyable `/final4` URLs to the Admin OBS card with clear visibility coordination instructions.
  5. Test Coverage: Comprehensive tests for route isolation, state transitions, centering stability, and regression.
