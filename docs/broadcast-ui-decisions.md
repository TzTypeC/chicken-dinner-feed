# Broadcast UI & PMCC 2026 Visual Identity — Architectural Decisions

Status of each design and architectural decision for **Part 3: Final-4 Leaderboard, WWCD Celebration, Post-Game Standings & PMCC 2026 Theme**.

---

## Decision Matrix (`D-PMCC-01` – `D-PMCC-07`)

| ID | Topic | Proposed Decision | Rationale & Source Evidence | Status |
| :--- | :--- | :--- | :--- | :--- |
| **`D-PMCC-01`** | **Persistent Team Slot (`teamNo`) Format & Placement** | Render canonical `team.teamNo` as a compact, tabular `T01`–`T25` badge in burnished bronze/gunmetal inside the Team cell (`[Logo] [T05] [Team Name]`) on the Live Leaderboard, Final-4 cards, WWCD screen, and Post-Game Standings. Add `showTeamNumbers: boolean` (default `true`) to `OverlayAppearance`. | Avoids adding a 7th column that would squeeze team names on the `376px` leaderboard tower, while making `T05` (Team Slot) visually unmistakable from `#1` (Live Rank). | `APPROVED` |
| **`D-PMCC-02`** | **Automatic Final-4 Leaderboard Trigger & 3/2-Team Grayed Retention** | Automatically transition `/overlay/:instanceId` from the vertical tower to the 4-column top-center horizontal squad bar when `showFinalFourLayout !== false`, `match.phase !== 'idle'`, `standingTeamCount` reaches `4` (and `eliminatedCount >= 1`). Keep all 4 cards visible when `3` or `2` teams remain alive by rendering eliminated Final-4 squads in a grayed-out knocked/eliminated state (`OUT #4` / `OUT #3`, gray alive bars) rather than removing their card. Only revert to the vertical tower when `standingTeamCount >= 5` (or new match/warmup), and transition to WWCD when `standingTeamCount === 1`. | Confirmed in `A1`: preserves the 4-card top-bar geometry throughout the final circle (`4 → 3 → 2` alive teams) and gives viewers immediate visual feedback on which of the Final 4 squads have been knocked out. | `APPROVED` |
| **`D-PMCC-03`** | **WWCD Victory Screen Delivery & Survivor Display** | Support **both**:<br>1. Automatic transition on `/overlay/:instanceId` when `showWwcdOverlay !== false` and `standingTeamCount === 1` (with `eliminatedCount >= 1`), AND<br>2. Dedicated routes `/overlay/wwcd` & `/overlay/:instanceId/wwcd` (which also fall back to the latest closed map's `#1` winner).<br>In PCOB Mode, display the 4 squad players' real names, alive state, and individual kills; in Manual Mode, display the 4-bar visual `AlivePlayerBars` + `SURVIVORS: X/4` (never synthetic `"Slot 1"` names). | Confirmed in `A2`: gives broadcast directors flexibility to use either a single all-in-one OBS Browser Source or dedicated OBS scene sources, while respecting real data availability in PCOB vs. Manual Mode. | `APPROVED` |
| **`D-PMCC-04`** | **Post-Game Detailed Standings (`/overlay/postgame`) Data & Layout** | Create `/overlay/postgame` and `/overlay/:instanceId/postgame` backed by persisted `ClosedMapResult` (delivered live over `/ws/live` via `snapshot.lastClosedMap` whenever a map closes or is edited in `Series control`, with fallback to finished live match state if not yet closed). Left panel spotlights `#1 WWCD Winner`; right panel renders a structured table of all teams (`#1–#25`: `#`, `Logo`, `T##`, `Team`, `PLACE`, `ELIMS`, `PLACE PTS`, `ELIM PTS`, `MATCH PTS`) sorted by Total Match Points that automatically splits into 2 balanced columns when `> 12` teams exist so up to 25 teams fit on `1920×1080` with zero scrolling. | Confirmed in `A3`: prevents data loss when the next lobby loads, clearly separates single-match points (`PLACE PTS + ELIM PTS = MATCH PTS`) from series points, and guarantees 1080p legibility without vertical scrollbars. | `APPROVED` |
| **`D-PMCC-05`** | **Post-Game Custom Background Media (`image` / `video`, `opacity`, `blur`)** | Add `BackgroundMediaStore` (`backend/data/backgrounds/`, magic-byte validated `PNG`/`JPG`/`WebP`/`MP4`/`WebM`, `POST/DELETE /api/overlays/:instanceId/background`, included in Backup ZIP) and `postGameBackground` config (`mode: 'disabled' \| 'image' \| 'video'`, `mediaUrl`, `opacity: 0..100`, `blur: 0..24`). Render inside an isolated `z-0 overflow-hidden` background layer with edge-scale compensation so foreground UI (`z-10`) stays 100% sharp and surrounding canvas stays transparent when disabled. | Reuses the proven `LogoStore`/`FontStore` pattern without external dependencies and guarantees CSS blur never leaks onto text or outside the 1920×1080 frame. | `APPROVED` |
| **`D-PMCC-06`** | **Global PMCC 2026 Visual Theme (`KV_2026 PMCC ID.png`)** | Update default `OverlayAppearance` to `backgroundColor: '#160F0A'` (Deep Espresso Obsidian), `textColor: '#F9EDD9'` (Parchment Ivory), `accentColor: '#E5A93C'` (PMCC Nib-Trophy Gold), automatically migrate saved instances that still have the old factory slate/amber defaults (`#0F172A` / `#F8FAFC` / `#F59E0B`), apply architectural `1px` bronze (`#816036`) borders with `◇` diamond nodes and crimson (`#A83820`) elimination accents across all overlays, align the Admin UI theme in `globals.css`, and add a 1-click **"Apply PMCC 2026 Theme"** button in `AppearanceEditor`. | Confirmed in `A4`: directly grounded in pixel sampling of `assets/KV_2026 PMCC ID.png` and automatically upgrades unmodified instances while preserving custom operator palettes. | `APPROVED` |
| **`D-PMCC-07`** | **Admin Multi-Mode Live Preview & OBS URL Directory** | Extend `OverlayPreview.tsx` in the Admin Overlays tab with preview mode selectors / test triggers (`Standard Tower`, `Final-4 Bar`, `WWCD Victory`, `Post-Game Standings`, plus `Match Info` & `Elimination Alert` layers) and add copyable OBS Browser Source URLs for `/overlay/:id/wwcd` and `/overlay/:id/postgame`. | Lets operators preview and tune Final-4, WWCD, and Post-Game Background blur/opacity live inside the Admin panel without needing an active end-game lobby. | `APPROVED` |
